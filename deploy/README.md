# Запуск на своём сервере

Чтобы публиковать по-настоящему, нужен сервер, который работает круглосуточно, с HTTPS-адресом.
Через этот адрес соцсети возвращают вас после входа, а Instagram скачивает видео.

## Вариант А: Google Cloud (бесплатная машина)

У Google Cloud есть бесплатная машина e2-micro, но не всё в ней бесплатно:

- **Сама машина** (e2-micro в США) и диск 30 ГБ — бесплатно.
- **Постоянный IP-адрес** — по ценам Google, скорее всего около $3–4 в месяц. Уточните по счёту после первых дней.
- **Исходящий трафик** — 1 ГБ в месяц бесплатно. Сверх этого центы: каждое видео отправляется в Instagram, TikTok и X, но при небольшом объёме это копейки.

Шаги:

1. Зарегистрируйтесь на [console.cloud.google.com](https://console.cloud.google.com/). Нужна банковская карта; проект «My First Project» создастся сам.
2. Откройте **Cloud Shell** — кнопка **«>_»** справа вверху консоли.
3. Вставьте команду и нажмите Enter:

   ```bash
   curl -fsSL https://raw.githubusercontent.com/serezhaOk/postpostpost/main/deploy/gcloud.sh | bash
   ```

   Скрипт создаст машину, постоянный IP и правила доступа, а затем установит приложение. Займёт 5–10 минут.
   В конце он покажет адрес (вида `https://34-123-45-67.sslip.io`) и пароль.
4. На всякий случай поставьте лимит расходов: **Billing → Budgets & alerts → Create budget**, например на $5 — придёт письмо, если расходы к нему подойдут.

Если Cloud Shell спросит разрешение (Authorize) — соглашайтесь. Если скрипт оборвался, запустите его снова — он продолжит с того же места.

## Вариант Б: любой VPS

Подойдёт любой VPS с Ubuntu 24.04: 1 ГБ памяти, 20+ ГБ диска (видео хранятся на сервере).
Например, Hetzner CX22 (около €4 в месяц) или DigitalOcean Basic (около $6 в месяц).

**Важно: сервер должен быть не в России.** Instagram и X оттуда недоступны, и публикация не пройдёт.

Подключитесь к серверу по SSH и выполните:

```bash
curl -fsSL https://raw.githubusercontent.com/serezhaOk/postpostpost/main/deploy/install.sh | sudo bash
```

Скрипт поставит Docker и запустит приложение вместе с Caddy (он сам выпускает HTTPS-сертификат).
В конце он покажет адрес и пароль для входа.

Он спросит домен:

- **Есть свой домен** — заранее создайте у регистратора A-запись на IP сервера и введите домен.
- **Нет домена** — нажмите Enter. Скрипт возьмёт бесплатный адрес вида `1-2-3-4.sslip.io`, он сразу указывает на ваш сервер.

Обновление до новой версии — та же команда.

## Подключение соцсетей

Откройте адрес с телефона или компьютера → ⚙️ **Настройки** → у нужной соцсети **«Настроить»**.
Там пошаговая инструкция, адрес возврата копируется кнопкой, ключи вставляются прямо в форму.
После сохранения откроется вход в соцсеть — разрешите доступ, и аккаунт подключён.

## Уведомления в Telegram (по желанию)

Через Telegram приходят сообщения о сбоях, об истёкшем доступе и о видео во «Входящих» TikTok.

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Напишите своему боту любое сообщение.
3. Узнайте свой chat id у [@userinfobot](https://t.me/userinfobot).
4. Впишите оба значения в `/opt/postpostpost/deploy/.env` на сервере и перезапустите.
   В Google Cloud на сервер можно зайти из Cloud Shell командой `gcloud compute ssh postpostpost --zone us-central1-a`.

```bash
cd /opt/postpostpost/deploy && sudo docker compose up -d
```

## Где что лежит

| | |
|---|---|
| `/opt/postpostpost/deploy/.env` | домен, пароль, настройки |
| `/opt/postpostpost/deploy/data/` | база и загруженные видео — это стоит бэкапить |
| `sudo docker compose logs -f app` | логи (из папки `deploy`) |
